# Xerion Oracle: передбачення дня

Мінісайт для QR-коду на кружці. Користувач тапає по кулі або трусить телефон і отримує одне з 365 передбачень українською чи англійською. На одному телефоні показується одне передбачення на день, без повторів протягом року.

**Адреса сайту:** https://foffpls.github.io/xerion-oracle/
**QR на кружці веде на:** https://foffpls.github.io/xerion-oracle/?src=mug
**Адмінка:** https://foffpls.github.io/xerion-oracle/admin.html

> Не перейменовуй репозиторій і акаунт: адреса з QR зашита в кружки.

## Файли

| Файл | Що це |
|---|---|
| `index.html` | Сам сайт (куля, анімація, таймер, поширення) |
| `admin.html` | Адмінка: експорт/імпорт .xlsx і публікація |
| `predictions.json` | Тексти передбачень. Сайт читає їх звідси |
| `logo.png`, `mark.png` | Лого Xerion |
| `og.png` | Прев'ю посилання в месенджерах і соцмережах |
| `favicon.png`, `apple-touch-icon.png` | Іконки |
| `.nojekyll` | Службовий файл для GitHub Pages, не видаляй |

## Перший запуск на GitHub Pages

1. Створи **публічний** репозиторій `xerion-oracle` в акаунті `foffpls`.
2. Завантаж у корінь репозиторію всі файли з цієї папки, включно з `.nojekyll`. Через веб: *Add file → Upload files*. Або через git:
   ```bash
   git init && git add . && git commit -m "Xerion Oracle"
   git branch -M main
   git remote add origin git@github.com:foffpls/xerion-oracle.git
   git push -u origin main
   ```
3. У репозиторії відкрий **Settings → Pages**, вибери *Source: Deploy from a branch*, *Branch: main / (root)* і натисни *Save*.
4. Через 1–2 хвилини сайт з'явиться за адресою https://foffpls.github.io/xerion-oracle/.
5. **Перед друком кружок** відскануй QR телефоном і переконайся, що сайт відкривається.

## Як оновити тексти

1. Відкрий `admin.html` і натисни **Завантажити .xlsx**.
2. Відредагуй файл в Excel або Google Sheets. Аркуш *Інструкція* всередині файлу пояснює кожну колонку.
3. В адмінці натисни **Обрати .xlsx**. Адмінка перевірить файл, покаже, що додано, змінено чи видалено, і попередить про дублікати та задовгі тексти.
4. Натисни **Опублікувати**. Сайт оновиться через 1–2 хвилини.

### Токен для кнопки «Опублікувати» (потрібен один раз)

GitHub → *Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token*:

- **Repository access:** Only select repositories → `xerion-oracle`
- **Permissions → Repository permissions → Contents:** Read and write
- Термін дії вибери сам. Коли він закінчиться, просто створи новий токен.

Встав токен в адмінці. Галочка «Запам'ятати» зберігає його тільки у твоєму браузері. На сервер чи в репозиторій токен не потрапляє.

Без токена теж можна: натисни **Завантажити predictions.json** і заміни цей файл у репозиторії через *Add file → Upload files*.

## Корисні параметри адреси

- Скинути своє передбачення для тесту: в адмінці кнопка **«Скинути моє передбачення на сьогодні»**. Вона працює тільки для браузера, в якому відкрита адмінка.
- `?preview=random`: тест анімації з випадковим передбаченням, нічого не зберігає. Тапай кулю ще раз, щоб отримати інше.
- `?preview=ID`: показує конкретне передбачення і нічого не зберігає. Посилання «перегляд» в адмінці використовують саме його.
- `?src=mug`, `?src=story`, `?src=telegram`…: мітки джерела переходу для майбутньої аналітики.

## Як працює логіка

- При першому візиті телефон отримує випадковий «seed». Стан зберігається у localStorage і дублюється в cookie, тож закриття сторінки чи браузера нічого не скидає.
- Кожного дня з ще не показаних передбачень детерміновано вибирається одне. Повтори почнуться лише тоді, коли закінчаться всі тексти.
- Після показу запускається таймер до опівночі за місцевим часом. Повторний тап показує повідомлення «Куля вже сказала своє».
- Якщо користувач очистить дані браузера, лічильник почнеться заново.
- 10 передбачень позначені як **легендарні** (`legendary = 1`). Для них куля стає золотою і з'являються іскри.
- Струшування: на Android працює одразу. На iPhone спершу треба натиснути кнопку «Увімкнути потрусити», бо так вимагає Apple.
